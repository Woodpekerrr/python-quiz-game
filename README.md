# 🎮 Python Quiz Game

โปรแกรมเกมตอบคำถามแบบปรนัย พัฒนาด้วยภาษา Python และ Tkinter  
ผู้เล่นสามารถตอบคำถาม เก็บคะแนน ดูประวัติคะแนน และเล่นใหม่ได้

โปรเจกต์นี้พัฒนาขึ้นเพื่อฝึกการเขียนโปรแกรมด้วย Python
และใช้เป็นหนึ่งในผลงานสำหรับ Portfolio

---

## 📌 เกี่ยวกับโปรเจกต์

Python Quiz Game เป็นโปรแกรม Desktop Application สำหรับ Windows
ที่ให้ผู้เล่นตอบคำถามแบบ Multiple Choice

คำถามจะถูกอ่านจากไฟล์ JSON และระบบจะสุ่มลำดับคำถามทุกครั้งที่เริ่มเกม

เมื่อเล่นจบ ผู้เล่นสามารถกรอกชื่อเพื่อบันทึกคะแนน
โดยคะแนนจะถูกเก็บไว้ในไฟล์ CSV ภายในเครื่องของผู้ใช้งาน

---

## ✨ ความสามารถของโปรแกรม

- ระบบตอบคำถามแบบ Multiple Choice
- สุ่มลำดับคำถามทุกครั้งที่เริ่มเกม
- คำนวณคะแนนอัตโนมัติ
- กรอกชื่อผู้เล่นหลังจบเกม
- บันทึกประวัติคะแนน
- แสดง Scoreboard
- แสดงคะแนนย้อนหลัง
- เล่นเกมใหม่ได้
- ลบประวัติคะแนนทั้งหมดได้
- สามารถใช้งานเป็นไฟล์ `.exe`
- ไม่จำเป็นต้องติดตั้ง Python สำหรับผู้ที่ดาวน์โหลดไฟล์ `.exe`
